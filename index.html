GIT

o git é um controle de versão distribuido.

Comandos do git

  • git init : inicializa um repositório git
  • git status
  • git add arquivo.txt : Adiciona no stage
  • git commit -m "Comentario" : Cria um commit no seu repositóiro local
  • git log : Exibe os commits do branch atual do repositório local
  • git switch branch : muda de branch
  • git switch branch -c cria-nova-branch : muda de branch
  • git diff : exibe a diferença do commit apontado por HEAD e worktree
