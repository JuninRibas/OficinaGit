História da Internet e da Web

A Internet e a Web não são a mesma coisa: a Internet surgiu antes e a Web foi construída sobre ela. Esta página apresenta a evolução das duas.

Linha do tempo

  1. Redes de computadores (anos 1960): surgem a comutação de pacotes e as primeiras redes ligando computadores.
  2. ARPANET (1969): rede militar/acadêmica dos EUA, considerada a precursora da Internet.
  3. TCP/IP (1983): padrão que permitiu interligar redes diferentes; a ARPANET migrou para ele.
  4. DNS (1983–1987): sistema que traduz nomes (como ifsc.edu.br) em endereços IP.
  5. Tim Berners-Lee (1989): no CERN, propôs um sistema de informação com documentos ligados por hipertexto.
  6. World Wide Web (1990–1991): nasce a Web, aberta ao público em 1991.
  7. HTML: linguagem de marcação para descrever páginas e links.
  8. HTTP: protocolo de requisição e resposta entre cliente e servidor.
  9. Navegador: o primeiro, WorldWideWeb (1990), exibia e editava páginas.
  10. Servidor web: programa que armazena páginas e as entrega por HTTP (o primeiro rodava no CERN).
  11. Web 1.0 × Web moderna: a Web 1.0 tinha páginas estáticas, só de leitura; hoje há aplicações interativas, como redes sociais, e-mail e editores online.

Glossário

Internet
Rede mundial de redes interligadas pelo TCP/IP.
Web
Serviço de documentos ligados por hipertexto, acessados via HTTP.
Protocolo
Conjunto de regras para dois sistemas se comunicarem.
Endereço IP
Identificador de um dispositivo na rede (IPv4 ou IPv6).
