HTTP na prática: requisição e resposta

O papel do HTTP

HTTP (HyperText Transfer Protocol) é o protocolo que define como o navegador pede páginas e outros recursos a um servidor web, e como o servidor responde.

Cliente, servidor, requisição e resposta

  • Cliente: quem faz o pedido (normalmente o navegador).
  • Servidor: quem guarda os recursos e responde.
  • Requisição: a mensagem enviada pelo cliente.
  • Resposta: a mensagem devolvida pelo servidor.

Métodos GET e POST

  • GET: pede um recurso; os parâmetros vão na URL e o método não deve alterar dados no servidor.
  • POST: envia dados no corpo da requisição (ex.: formulários, cadastros).

Exemplo de requisição

GET /index.html HTTP/1.1
Host: www.exemplo.com.br
User-Agent: Mozilla/5.0
Accept: text/html

Exemplo de resposta

HTTP/1.1 200 OK
Content-Type: text/html; charset=UTF-8
Content-Length: 1256

<!DOCTYPE html>
<html> ... </html>

Códigos de status (estados) HTTP

CódigoNomeSignificado
200OKRequisição bem-sucedida.
301Moved PermanentlyRecurso mudou de endereço definitivamente.
400Bad RequestRequisição malformada ou inválida.
403ForbiddenAcesso proibido, mesmo que o recurso exista.
404Not FoundRecurso não encontrado.
500Internal Server ErrorErro interno no servidor.
